turbosms-go
===========

Golang client for the [TurboSMS](https://turbosms.ua/) SOAP gateway. Built on top of code generated by the [gowsdl](https://github.com/hooklift/gowsdl) tool.

**Note:** SOAP is the legacy TurboSMS protocol. For new projects consider the current [HTTP API](https://turbosms.ua/en/api.html), which also supports Viber messages. This library covers only the SOAP gateway.

**Warning:** the official SOAP endpoint works over plain HTTP (`http://turbosms.in.ua`) and HTTPS is not available there. Your login, password and message texts are sent unencrypted.

Examples
========

```golang
package main

import (
	"fmt"
	"log"

	sms "github.com/wildsurfer/turbosms-go"
)

func main() {
	c := sms.NewClient("username", "password")
	r, err := c.GetCreditBalance()

	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("Credit balance: %s\n", r.GetCreditBalanceResult)
}
```

```golang
package main

import (
	"fmt"
	"log"

	sms "github.com/wildsurfer/turbosms-go"
)

func main() {
	c := sms.NewClient("username", "password")
	r, err := c.SendSMS("testname", "+123469563457", "Test message", "")

	if err != nil {
		log.Fatal(err)
	}
	for _, s := range r.SendSMSResult.ResultArray {
		fmt.Println(s)
	}
}
```

Error handling
--------------

The gateway reports message level failures as text inside `SendSMSResult.ResultArray`. In this case `err` stays `nil`, because the SOAP call itself succeeds. For example, when the account does not have enough credits, the result array contains a string like `Не хватает N кредитов для отправки SMS`. The texts are localized and have no stable format, so the library does not try to parse them. Always check the returned strings after sending, do not rely on `err` alone.
